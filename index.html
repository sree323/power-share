ABOUT THE PROJECT

Built for easier EV discovery

Charging Point is a student-friendly front-end prototype made with HTML, CSS and JavaScript. It demonstrates station discovery, filtering and a simulated reservation flow. It does not connect to real chargers, payment providers or live location services.
